Algorithme pour la repartition équilibrée des élèves par classes.

Avant de lancer le programme (opti_leve.exe) : 

- Vérifier que les paramètres sont bien respecté dans le fichier .ini (principalement le nombre de classe souhaité, mais aussi les poids de chaque critères) : uniquement changer les valeurs, ne pas toucher aux noms de variables

- Entrer tous les élèves dans le fichier eleves.csv 
    /!\ attention /!\ avec l'utilisation d'excel ou equivalent : il faut bien sauvegarder sous le meme format de sorte a ce que le séparateur de colonnes soit des points virgules (;)

- Lancer le programme en double cliquant dessus et cela va générer les fichiers CSV 

- Si vous le lancez dans un terminal (ex PowerShell) vous aurez aussi accès aux performances de la repartition (moyennes des équilibre par classe)
